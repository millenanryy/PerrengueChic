# Perrengue Chic

Catálogo estático baseado no arquivo `Frame 151.webp`. O banner e as fotos foram recortados da referência. A última linha, cortada no arquivo original, não foi incluída.

Execute `python3 -m http.server 8000 --bind 0.0.0.0` na raiz para visualizar. As seções e preços estão em `catalogo.js`; os códigos são gerados pelo catálogo. Confira o perfil de atendimento nos links em `index.html` antes de publicar. O site não recebe pagamentos nem gerencia estoque.

O site está organizado em uma única página, com navegação por âncoras, catálogo filtrável e atendimento externo pelo Instagram. Não há formulário, carrinho ou checkout. Quando houver domínio definitivo, configure a URL canônica, `og:url`, `og:image` absoluta e, se necessário, o sitemap.
